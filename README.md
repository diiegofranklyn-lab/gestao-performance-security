# Gestão de Performance — Security | John Deere

Aplicação web corporativa para gestão de performance dos coordenadores de segurança.

## Módulos
- Dashboard executivo
- Avaliação 180°
- Ranking de performance
- PDI
- Cadastro central de coordenadores
- Filtros por período e unidade
- Exportação dos dados
- Layout responsivo para desktop e celular

## Modelo de avaliação
Os pilares seguem a estrutura corporativa do arquivo-base:
- KPIs Operacionais — 30%
- Desenvolvimento da Liderança — 20%
- Qualidade Operacional e Segurança — 20%
- Inovação e Melhoria Contínua — 15%
- Gestão do Cliente e Compliance — 15%

Escala: 1 a 5.

## Publicação
O projeto é uma SPA estática e pode ser publicado no GitHub Pages. Os dados desta primeira versão ficam no navegador (localStorage). Para uso corporativo multiusuário, a próxima evolução deve conectar autenticação e banco de dados (por exemplo, Supabase, Firebase ou outro backend aprovado pela empresa).
